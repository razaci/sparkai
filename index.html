How did it decide?

This is a multinomial Naive Bayes classifier. It counts words in each label, uses smoothing so unseen words don’t break it, and combines those patterns into a score.

The prediction’s word evidence will appear here.
See the idea in code
// For each label, start with its frequency.
score = Math.log(labelExamples / allExamples);

// Add evidence for each word.
score += Math.log(
  (wordCount + 1) / (labelWordTotal + vocabularySize)
);

// Compare label scores. Higher wins.
// +1 is "smoothing": it avoids zero probabilities.
Try to break it

Test “not happy.” Does it notice “not”? Add examples containing negation and test again. A word-count model ignores word order, which limits what it can learn.

Does more data always help?

Write six new sentences on paper first: three positive and three negative. Keep them out of training. Test, record correct predictions, add balanced training examples, and test the same six again.

Accuracy = correct predictions / all test sentences
Example: 4 correct out of 6 = about 67%

A few things real developers know

AI is built from choices

People choose the examples, labels, and model. Uneven or misleading examples can produce uneven or misleading predictions. A high model score is not proof that an answer is correct.

Rules and learning are different

The webpage bot follows your if/else rules. The classifier estimates patterns from labeled data. Large language models are much more complex than either demonstration.

Errors are part of the work

Predict what will happen, run the code, observe, and change one thing. That loop is programming.
